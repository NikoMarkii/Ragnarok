# Boss Configuration

MOD全体の共通設定は `RagnarokConfig` で管理します。ゲームまたはサーバーを起動すると `config/ragnarok-common.toml` が生成されます。
開発環境で `runClient` / `runServer` を使用する場合は `run/config/ragnarok-common.toml` です。
ゲーム・サーバーを終了してから編集し、再起動してください。マルチプレイではサーバー側の設定が適用されます。

| セクション | ボス | health | attack_damage | armor | damage_cap |
| --- | --- | ---: | ---: | ---: | ---: |
| bosses.gradius | グラディウス | 500.0 | 18.0 | 12.0 | 21.0 |
| bosses.dinocampus | ディノカムポス | 450.0 | 28.0 | 15.0 | 21.0 |
| bosses.galeos | ガレオス | 200.0 | 10.0 | 10.0 | 0.0 |
| bosses.ender_soldier | エンダーソルジャー | 200.0 | 12.0 | 15.0 | 0.0 |

上記は既存のバランスに合わせた初期値です。中ボスのダメージキャップは初期状態では無効です。

例: ディノカムポスの設定

```toml
[bosses.dinocampus]
health = 600.0
attack_damage = 32.0
armor = 18.0
damage_cap = 25.0
```

- `health`: 基礎最大HP。範囲1～1024。2ポイントがハート1個分です。
- `attack_damage`: 基礎攻撃力。範囲0～2048。各技の倍率や形態変化による補正が加わります。
- `armor`: 基礎防御力。範囲0～30。既存の防具・属性補正は維持されます。
- `damage_cap`: 1回の被ダメージ上限。範囲0～1000000。0で上限のみ無効になります。

ダメージキャップは防御力やボス固有の軽減より前に適用します。上限21でも実際に失うHPは21未満になることがあります。
防御貫通ダメージにも上限を適用しますが、`/kill` など無敵を無視するダメージは対象外です。
グラディウスのガードや覚醒中の無敵、連続ヒット軽減・適応耐性は引き続き有効です。

新規スポーンと保存済み個体の読み込み時に能力値を反映します。
最大HPが変更された場合、残りHPの割合を維持します。例えば250/500の個体を最大HP600に変更すると300/600になります。
属性の基礎値を設定するため、コマンドで個別に変更した基礎値も次回の読み込み時に設定値で更新されます。

グラディウスの青い火球、ディノカムポスの泡の直撃とブロック波は、設定した基礎攻撃力に比例します。
炎上・窒息・落雷などの追加効果によるダメージと効果時間は個別の既存設定に従います。
`attack_damage = 0` はこれらの追加効果や形態補正まで無効にする設定ではありません。

基礎値の設定方法はこのMOD向けの実装です。Cataclysmと同じDPS制限などを新たに導入するものではありません。
